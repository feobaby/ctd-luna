Block-level Elements

This is a paragraph. Paragraphs are block-level elements, which means they take up the full width available and start on a new line.

This is a div. Divs are also block-level elements and are often used to group content together.

Another paragraph below the div shows how block-level elements stack vertically.

Inline Elements

Inline elements do not start on a new line. For example, this text is bold using the <strong> tag, and this text is italic using <em>. You can also have links inline with text.

This is a span element, click here, which is inline and can style only part of a line.
